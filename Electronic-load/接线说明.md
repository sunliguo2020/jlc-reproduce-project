# 电子负载接线说明

本文按仓库中的固件 `01 Software/ele_load/ele_load.ino` 和 V1.2 硬件资料整理。此项目有主板和面板两块 PCB；如果使用项目 PCB，应优先使用板间 FPC 连接器和 PCB 上的接口，不要把各个芯片拆开后再按通用模块图接线。

> **重要：固件、原理图和 PCB 存在需要先核实的差异。** 下文会分别列出代码使用的 GPIO 和原理图信号。不要仅凭代码宏定义给屏幕或背光接线。

## 1. 项目 PCB 的连接方式

1. 断电后，将面板 PCB 与主板 PCB 的对应 FPC 连接器相连。按连接器的 1 脚标记和触点方向插入，不要只按排线颜色判断方向。
2. 屏幕、旋转编码器及其板上信号按原理图由面板 PCB 布线；INA226、MCP4725 及负载驱动相关信号按主板原理图布线。
3. 不要把风扇或电子负载直接接到 ESP32 GPIO。GPIO 只用于控制板上的驱动电路。
4. 初次上电调试时不要接电池或功率负载。先检查供电极性、FPC 方向和对地短路，再通过 USB/限流电源启动。

## 2. 固件 GPIO 对照

| 功能 | ESP32 GPIO | 固件/备注 |
|---|---:|---|
| 负载使能控制 | 25 | `OUT_EN_PIN`；连接板上使能/驱动电路，不接负载电流端 |
| 风扇控制 | 14 | `FAN_CTL_PIN`；连接板上风扇驱动输入，不可直接驱动风扇 |
| 编码器 A | 19 | `PinA` |
| 编码器 B | 23 | `PinB` |
| 编码器按键 | 26 | `PinC`，内部上拉，按下时读低电平 |
| I2C SDA | 21 | ESP32 Arduino `Wire` 默认引脚；MCP4725 地址在代码中为 `0x60` |
| I2C SCL | 22 | ESP32 Arduino `Wire` 默认引脚 |
| 温度 ADC | 38 | 固件调用 `analogRead(38)`；与 V1.2 原理图上的 ESP32-PICO-D4 引脚需核对 |
| 另一个 ADC 读取 | 37 | 固件调用 `analogRead(37)`；与 V1.2 原理图上的 ESP32-PICO-D4 引脚需核对 |

固件启动时还会将 GPIO32、GPIO33、GPIO4 配置为输出，分别拉低、拉高、拉低。除非确认它们在对应硬件版本中的用途，不要把它们重新分配给外接模块。

## 3. 屏幕与面板信号

V1.2 原理图中的显示信号网名及对应 ESP32-PICO-D4 引脚如下。使用项目面板和主板时，通过板上 FPC/PCB 连接这些信号；若使用独立 TFT 模块，则还必须让 `TFT_eSPI` 的 `User_Setup` 与实际接线、屏幕控制器和分辨率匹配。

| 屏幕信号 | 原理图连接 |
|---|---|
| LCD_CLK / SCK | GPIO13 |
| LCD_CS | GPIO27 |
| LCD_D/C | GPIO5 |
| LCD_RST | GPIO18 |
| LCD_MOSI / SDA | 原理图连接到 ESP32-PICO-D4 的 SD3 引脚 |
| 电源 | 按屏幕/板卡标识接 3.3V 和 GND；不要向 3.3V 逻辑屏输入 5V |

**LCD_MOSI 需要重点核实：** 原理图把它接到 ESP32-PICO-D4 的 SD3（GPIO11/闪存接口）。这不是通用 ESP32 开发板上可随意用作 SPI 输出的安全默认引脚。若屏幕无显示，先核对实际 PCB 版本和这条网络；独立接线时应选用未被板上其他功能占用、且不属于闪存接口的 GPIO，并同步修改 `TFT_eSPI` 配置。不要直接照抄 SD3 接法到另一种 ESP32 模组。

### 背光与 GPIO26

- 固件定义了 `LCD_BL 26`，但没有初始化或驱动这个宏。
- GPIO26 同时被固件用作编码器按键输入（`PinC`），原理图也将 `KEY_C` 接到 GPIO26。
- 因此**不要把 LCD 背光线接到 GPIO26，也不要按“GPIO26 拉高即可点亮背光”来处理**。按项目面板 PCB 的背光电路和标识接线；独立 TFT 模块则按模块规格接背光，必要时使用合适的限流/驱动电路。

## 4. 传感器、DAC 与其他外设

| 外设 | 接线要点 |
|---|---|
| INA226 | 接板上 I2C 的 SDA、SCL、3.3V 和 GND；如果使用项目主板，按 INA226 所在板的原理图连接，不要将传感器电流端与逻辑电源混接 |
| MCP4725 DAC | 接 I2C 的 SDA、SCL、3.3V 和 GND；固件使用地址 `0x60` |
| 旋转编码器 | A 接 GPIO19，B 接 GPIO23，按键接 GPIO26；按键另一端接 GND。面板 PCB 已布线时使用面板连接器，不要再并接裸线 |
| 风扇 | 使用板上的风扇接口和驱动电路；GPIO14 仅为控制信号 |
| 负载使能 | GPIO25 是逻辑控制信号；功率输入、输出和采样电阻按主板 PCB/原理图连接，不能接到 ESP32 GPIO |

I2C 设备和逻辑电路应共地。确认使用的开发板和 Arduino ESP32 核心后，再确认 `Wire` 默认 SDA/SCL；如果默认引脚不同，应在代码中显式指定，并确保与 PCB 一致。

## 5. 屏幕不亮时的排查顺序

1. **先确认供电和方向：** 检查屏幕/面板是否得到正确电压、GND 是否共地、FPC 是否按 1 脚方向插好。
2. **确认背光：** 项目固件没有真正控制 `LCD_BL`。查看面板背光电源路径和实际 PCB 版本；仅有图像信号而无背光时，屏幕可能看起来全黑。
3. **确认 `TFT_eSPI` 配置：** 检查所选控制器、屏幕尺寸/偏移、SPI 引脚及复位脚是否与实际屏幕和 PCB 相符。草图自身没有包含 `TFT_eSPI` 的板级引脚配置。
4. **检查 MOSI 网络：** 项目 V1.2 原理图中的 LCD_MOSI 连到 SD3，需确认所用 ESP32-PICO-D4/PCB 是否确实可用；独立接线不要使用闪存接口 GPIO。
5. **看串口日志：** 串口监视器设置为 `115200`。固件在 `setup()` 初始化 TFT 后会循环查找 INA226；若没有找到，会每隔约 5 秒打印 `No INA found. Waiting 5s and retrying...`，此时 `setup()` 不会结束，`loop()` 中的 LVGL 刷新也尚未运行。先检查 I2C 连接和 INA226 是否被识别。
6. **核实硬件版本：** 固件读取 GPIO37/38，而原理图采用 ESP32-PICO-D4。若实际使用的是 V1.2 主板，应按对应原理图确认温度/电压 ADC 网络与芯片可用引脚，不能假设不同 ESP32 开发板的 GPIO 编号一致。
